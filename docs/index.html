Media Compressor

Shrink images and videos while keeping dimensions, frames and metadata.

100% local · nothing leaves this PC
Browser demo. Runs in this tab on your own files (Chrome/Edge on a computer): pick folders with Browse. Video is H.264 only (slow, ffmpeg.wasm); metadata and file dates are not preserved. AV1, H.265, GPU and lossless PNG optimising need the Windows app.
